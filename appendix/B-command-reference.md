| Command | શું કરે | નિશાન |
|---|---|---|
| `git clone https://github.com/deepseek-ai/dsh-superagent-prototype.git` | Repository લાવે | 🧪 |
| `git checkout 8c32a9dc5d72c033816c6a8110b37f40cf94fba4` | Pinned commit પર જાય | 🧪 |
| `pnpm install --frozen-lockfile` | Lockfile મુજબ packages (network જોઈએ) | 🧪 |

| `pnpm vitest run <file>` | એક test file | 🧪 |
| `pnpm vitest run <file> -t "<નામનો ભાગ>"` | નામથી tests | 🧪 |
| `pnpm exec tsc --noEmit` | ફક્ત type તપાસ | 🧪 |

## Service ચલાવવી (live)

| Command | શું કરે | નિશાન |
|---|---|---|
| `scripts/dsh-superagent start` | tmux માં service શરૂ ([script][script-service]) | ⚠️ |
| `scripts/dsh-superagent status` | JSON + exit code (0 સ્વસ્થ, 1 નથી ચાલતું, 2 અને 3 માણસની જરૂર) | ⚠️ |
| `scripts/dsh-superagent restart` | ફરી શરૂ | ⚠️ |
| `scripts/dsh-superagent stop` | બંધ | ⚠️ |

## Management API (live)

બધા requests માં header `x-orchestrator-request: 1` જોઈએ, અને host `127.0.0.1` ([પ્રકરણ 10](../book/10-panel.md)).

| Request | શું કરે | નિશાન |
|---|---|---|
| `GET /orchestrator/api/state` | Health અને સ્થિતિ | ⚠️ |
| `GET /orchestrator/api/sources` | Sources; dropped જવાબો | ⚠️ |
| `GET /orchestrator/api/tickets/<id>` | એક Ticket | ⚠️ |
| `GET /orchestrator/api/threads/<key>` | એક પાનું | ⚠️ |
| `POST /orchestrator/api/tickets/<id>/stop` | Ticket રોકે ([route][http-stop]) | ⚠️ (✅ route source માં) |
| `POST /orchestrator/api/triggers/<id>/requeue` | ફરી Eval ([route][http-requeue]) | ⚠️ (✅ route source માં) |
| `GET /orchestrator/api/prompts`, `PUT /orchestrator/api/prompts` | Team prompt sections | ⚠️ |
| `PUT /orchestrator/api/settings/<block>` | Settings block, `revision` સાથે | ⚠️ |

## પુસ્તકનાં પોતાનાં tools

આ commands **પુસ્તકના** repository ના root માંથી ચાલે છે.

|---|---|---|
